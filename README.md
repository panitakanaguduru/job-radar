# Job Radar

Auto-updated job board for Data Analyst, Software Engineer, and Sales Engineer roles.

**Live Dashboard:** https://YOUR_USERNAME.github.io/job-radar/

## Features
- 1,183 companies across Greenhouse, Ashby, Lever, Workday, SmartRecruiters
- US locations only
- Entry level / 1-3 years experience only
- Senior/lead/manager roles filtered out
- Jobs accumulate for 7 days
- Auto-updates every 6 hours via GitHub Actions
- OPT/H1B sponsorship flags
- Fortune 500 flags
- Download CSV

## Setup
1. Fork this repo
2. Go to Settings > Pages > Source: Deploy from branch `main` > Folder `/docs`
3. Wait for first Actions run (or trigger manually)
4. Open `https://YOUR_USERNAME.github.io/job-radar/`
